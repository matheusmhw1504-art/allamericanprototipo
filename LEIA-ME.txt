Pasta única para a Vercel: um link só para apresentar ao cliente.

Estrutura:
  index.html                 -> página de escolha das versões
  all-american-a-estante/    -> versão A
  all-american-b-lema/       -> versão B
  all-american-c-brilho/     -> versão C
  all-american-d-cafe/       -> versão D
  all-american-f-mix/        -> versão F (mix B + D)

Deploy pelo site:
1. vercel.com > Add New > Project > arraste a pasta "vercel" inteira.
2. Framework Preset: Other. Sem build command. Deploy.

Deploy pelo terminal:
  cd vercel
  npx vercel --prod

O link principal abre a página de escolha. Cada versão também tem link direto:
  seu-link.vercel.app/all-american-a-estante/
